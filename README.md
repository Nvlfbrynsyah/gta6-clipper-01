An iguana darts across the road as a red sports car closes in. This 30-second Short opens on that shot, replays it at lower speeds with two crops, and closes with a two-card make.fun pitch. FFmpeg uses a blurred vertical background to keep the wide shot visible and retains audio from the same trailer. [Official Rockstar source](https://www.rockstargames.com/VI/downloads)

`clip.mp4` is the upload file. `YOUTUBE_UPLOAD.txt` contains the title and description.

## Run it

Use Node.js 22.18 or later. The entry validates the URL and copies `VIDEO.json` to the output directory byte for byte.

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
